## 1. 结果和适用范围

LQR 是线性控制器，因此需要先线性化非线性动力学。正确顺序是：保留一般参数写出运动方程，解静态平衡方程，再在平衡点对状态和输入求偏导。theta_e 不为零不会增加状态数量，也不需要额外补一条运动方程；它会让配平角方程不再自动满足，并使 A、B 中的质量矩阵和重力导数都在 theta_e 处取值。

在平衡点附近令 delta_xi = xi - xi_e、delta_u = u - u_e，保留一阶小量后得到线性模型：

```text
delta_xi_dot = A_e*delta_xi + B_e*delta_u

A_e = partial(f)/partial(xi) evaluated at (xi_e, u_e)
B_e = partial(f)/partial(u)  evaluated at (xi_e, u_e)
```

下面先保留所有符号推导。数据表中的数字只作为来源清单记录；本轮不把它们代进平衡点、A 或 B。

保留腿质心偏离轮心—髋轴连线的距离 y 后，消去内力得到

```text
H(q) * q_ddot = r(q, q_dot) + D * u
q = [theta, x, phi]^T
u = [T, T_p]^T
```

因此非线性方程组的解就是 `q_ddot = inverse(H)*(r + D*u)`。第 6 节给出 H、r、D 的完整表达式，第 8 节给出连续 A、B 的每个非零元素，第 10 节给出真正的状态转移矩阵 `Phi(t) = expm(A*t)` 和离散矩阵。

最重要的变化：**y≠0 时，θ=φ=0、T=Tₚ=0 一般不是平衡点。** 若机体水平 φₑ=0，则近直立的无输入平衡点为

```text
theta_e = atan2(-m_p*y, m_p*L + M*L_t)
T_e = 0
T_p_e = 0
```

平衡点附近的状态应使用偏差量，不能默认把所有角度都拉到零。

本模型是**固定腿长、固定腿内构型的平面三刚体等效模型**。假设地面水平、轮纯滚动、左右同步，不计滚转/偏航、滑移、柔性、摩擦和传动损耗。腿作为一个等效刚体，Lₜ、L、y、Iₚ 在一次线性化中固定。它求解的是笔记给出的方程；若真实串联腿关节运动导致这些量随 θ、φ 变化，则需要从实际连杆拓扑重新建立动能，不能直接把本模型当作完整多体动力学。

## 3. 坐标系、位置与符号定义

世界平面坐标用 (X,Z)：X 向前，Z 向上。以下位置省略恒定轮半径 R 的竖向偏移，因此轮心可写成 W=(x,0)；加回 R 不改变任何加速度或线性化结果。

- W：轮心。
- H：机体髋转轴，轮心到髋轴的距离为 Lₜ。
- Gₚ：等效腿质心。
- Gₘ：机体质心。
- θ：W→H 相对竖直向上的倾角；θ>0 时髋轴向前。从车辆左侧、车头在画面左边看，θ 的正转动为逆时针。
- φ：机体基准线相对水平的角度；采用笔记的 Gₘ−H=(−l sinφ,l cosφ)，φ>0 时机体质心向后。从上述车辆左侧视角看，φ 的正转动为顺时针。因此笔记中“前仰”一词不能代替这里的明确坐标定义。补全右手系为 X 向前、Y 向车左、Z 向上时，机体角速度的 Y 分量为 −φ̇，腿角速度的 Y 分量为 θ̇。
- L：Gₚ−W 沿 W→H 的**轴向投影**，不是完整的轮心到质心欧氏距离。
- y：Gₚ−W 沿腿法向 n=(cosθ,−sinθ) 的有符号偏移。θ=0 时，y>0 表示质心在轮心前方，y<0 表示在后方。
- l：机体质心相对髋轴的距离；假设 φ=0 时质心恰好位于髋轴正上方。若存在额外水平偏置，还需再加一个机体偏心参数。

定义

```text
e = (sin(theta), cos(theta))
n = (cos(theta), -sin(theta))
```
```text
a = L*sin(theta) + y*cos(theta)
b = L*cos(theta) - y*sin(theta)
h = L_t*sin(theta)
z = L_t*cos(theta)
```

则所有位置完全确定为

```text
W   = (x, 0)
H   = (x+h, z)
G_p = (x+a, b)
G_m = (x+h-l*sin(phi), z+l*cos(phi))
```

Gₚ→H=(h−a,z−b)。轮心到腿质心距离为 √(L²+y²)，腿质心到髋轴距离为 √((Lₜ−L)²+y²)。表格原来的 L、L_M 描述沿用共线模型，加入 y 后必须明确这些不同的长度；Lₜ−L 只是上段轴向投影。

### 3.1 手写反三角函数与展开式的对应

手写的反三角函数用于描述“质心连线相对腿轴的偏角”，没有被忽略。下面保留原来的根号和 arctan，再逐项展开。`atan(...)` 与手写的 `arctan(...)` 是同一个反正切函数；这里用 beta_W、beta_H 表示两个质心偏角，与电机角 beta 无关。

```text
rho_W  = sqrt(L^2 + y^2)
rho_H  = sqrt((L_t-L)^2 + y^2)
beta_W = atan(y/L)
beta_H = atan(y/(L_t-L))

轮心到腿质心的水平、竖直分量：
a = rho_W*sin(theta + beta_W)
b = rho_W*cos(theta + beta_W)

腿质心到髋轴的水平、竖直分量：
h-a = rho_H*sin(theta - beta_H)
z-b = rho_H*cos(theta - beta_H)
```

当前 L>0 且 L_t-L>0，所以原式的 atan 写法与上述几何一致。推广到其他象限时分别使用 `atan2(y,L)` 和 `atan2(y,L_t-L)`，而不能只对比值取 atan。下列展开式无需计算这些反三角函数。

利用和角公式，可逐步得到：

```text
cos(beta_W) = L/rho_W
sin(beta_W) = y/rho_W

rho_W*sin(theta + beta_W)
  = rho_W*(sin(theta)*cos(beta_W) + cos(theta)*sin(beta_W))
  = L*sin(theta) + y*cos(theta)
  = a

rho_W*cos(theta + beta_W)
  = rho_W*(cos(theta)*cos(beta_W) - sin(theta)*sin(beta_W))
  = L*cos(theta) - y*sin(theta)
  = b

rho_H*sin(theta - beta_H)
  = (L_t-L)*sin(theta) - y*cos(theta)
  = h-a

rho_H*cos(theta - beta_H)
  = (L_t-L)*cos(theta) + y*sin(theta)
  = z-b
```

**这些等式是精确的三角恒等变换，不是小角度近似，也没有令 y=0。** 根号和反三角函数在代数展开后相互消去，偏心的物理作用仍由 y 项保留。小扰动线性化是后续第 8 节才进行的步骤。

T 定义为驱动轮向前滚动的正驱动力矩，从车辆左侧、车头在画面左边看，对轮为逆时针。Tₚ 定义为作用在机体上、沿 φ 正方向的力矩，在此视角对机体为顺时针；反作用在腿上的力矩为逆时针，恰好是 θ 正方向，所以**腿方程和机体方程均出现 +Tₚ 是正确的**。轮反力矩在腿方程中为 −T。若全部用统一朝向车左的 Y 轴表示，轮力矩为 +T，腿上执行器力矩为 −T+Tₚ，机体执行器力矩为 −Tₚ。具体实物检查和接口换算见主文第 7 节。

### 4.2 不同腿长的数据

笔记提出 L≈c₁Lₜ、y≈y₀+c₂Lₜ。当前只能计算 c₁=134.182/212.48≈0.631504。单个数据点无法同时确定 y₀、c₂，也不能证明 c₁ 恒定或 I_p 恒定。应对实际串联构型采集多组 (Lₜ,L,y,I_p)，并覆盖预期控制范围；当前不能用这一个姿态直接生成整个腿长范围的可信增益。

## 5. 原始方程及展开

内力按表定义：N、P 是轮对腿的水平/竖直力，N_M、P_M 是腿对机体的水平/竖直力，N_f 是地面对轮的水平摩擦力。正方向均为世界 X 正向、Z 正向。

轮：

```text
m_w*x_ddot = N_f - N
I_w*x_ddot/R = T - N_f*R
```
```text
(m_w + I_w/R^2)*x_ddot = T/R - N
```

### 5.1 手写腿方程原式（保留根号和反三角函数）

以下将手写的时间二阶导数记为 `d2_dt2(...)`，表示对括号内的整个位置表达式求二阶时间导数。L、y、L_t 按固定构型常量处理。

```text
N - N_M = m_p*d2_dt2(
    x + sqrt(L^2+y^2)*sin(theta + atan(y/L))
)

P - P_M - m_p*g = m_p*d2_dt2(
    sqrt(L^2+y^2)*cos(theta + atan(y/L))
)

I_p*theta_ddot
  = P*sqrt(L^2+y^2)*sin(theta + atan(y/L))
    + P_M*sqrt((L_t-L)^2+y^2)*sin(theta - atan(y/(L_t-L)))
    - N*sqrt(L^2+y^2)*cos(theta + atan(y/L))
    - N_M*sqrt((L_t-L)^2+y^2)*cos(theta - atan(y/(L_t-L)))
    - T + T_p
```

### 5.2 将原式展开为便于消元的形式

依次代入第 3.1 节的四个恒等式，腿平动先变为：

```text
N - N_M       = m_p*d2_dt2(x+a)
P - P_M-m_p*g = m_p*d2_dt2(b)

da/dtheta = b
db/dtheta = -a

a_ddot =  b*theta_ddot - a*theta_dot^2
b_ddot = -a*theta_ddot - b*theta_dot^2
```

因此腿平动的加速度展开式为：

```text
N - N_M = m_p*(x_ddot + b*theta_ddot - a*theta_dot^2)
```
```text
P - P_M - m_p*g = m_p*(-a*theta_ddot - b*theta_dot^2)
```

腿绕自身质心转动，按 θ 正方向（从车辆左侧、车头在画面左边看为逆时针）：

```text
I_p*theta_ddot = P*a + P_M*(h-a) - N*b - N_M*(z-b) - T + T_p
```

这与第 5.1 节的手写长三角式逐项相同：P 对应 a，P_M 对应 h−a，N 对应 b，N_M 对应 z−b，四个力臂均保留。再代入下述机体方程和轮方程消去内力，才得到第 6 节的 H、r、D。

机体平动：

```text
N_M = M*(x_ddot + z*theta_ddot - h*theta_dot^2
         - l*cos(phi)*phi_ddot + l*sin(phi)*phi_dot^2)
```
```text
P_M = M*(g - h*theta_ddot - z*theta_dot^2
         - l*sin(phi)*phi_ddot - l*cos(phi)*phi_dot^2)
```

机体绕自身质心转动：

```text
I_M*phi_ddot = T_p + N_M*l*cos(phi) + P_M*l*sin(phi)
```

先用机体平动消去 N_M、P_M，再用腿平动消去 N、P，最后使用轮方程消去 N_f，即得到下节。

## 6. 方程组的完整解

定义 `m_0 = m_w + I_w/R^2`，`rho^2 = L^2 + y^2`。

```text
H = [ h11  h12  h13
      h12  h22  h23
      h13  h23  h33 ]

h11 = I_p + m_p*rho^2 + M*L_t^2
h12 = m_p*b + M*z
h13 = -M*L_t*l*cos(theta + phi)
h22 = m_0 + m_p + M
h23 = -M*l*cos(phi)
h33 = I_M + M*l^2
```

```text
r = [r1, r2, r3]^T

r1 = g*(m_p*a + M*h) - M*L_t*l*sin(theta+phi)*phi_dot^2
r2 = (m_p*a + M*h)*theta_dot^2 - M*l*sin(phi)*phi_dot^2
r3 = M*g*l*sin(phi) - M*L_t*l*sin(theta+phi)*theta_dot^2

D = [ -1    1
      1/R   0
       0    1 ]
```

```text
[theta_ddot, x_ddot, phi_ddot]^T = inverse(H)*(r + D*u)
```

实现时使用线性求解 `H\rhs` 或 `numpy.linalg.solve(H,rhs)`，不必显式计算逆矩阵。

### 6.1 如需完全标量形式

把 H 的元素记为 hᵢⱼ，设

```text
C11 = h22*h33 - h23^2
C22 = h11*h33 - h13^2
C33 = h11*h22 - h12^2
C12 = h13*h23 - h12*h33
C13 = h12*h23 - h13*h22
C23 = h12*h13 - h11*h23
```
```text
Delta = h11*C11 + h12*C12 + h13*C13
```

设 v=r+Du，则

```text
theta_ddot = (C11*v1 + C12*v2 + C13*v3)/Delta
```
```text
x_ddot = (C12*v1 + C22*v2 + C23*v3)/Delta
```
```text
phi_ddot = (C13*v1 + C23*v2 + C33*v3)/Delta
```

在正质量、正惯量的有效构型下 H 为正定质量矩阵，Δ>0。若参数导致非正定，应先检查参数口径和坐标，而不是继续求 LQR。

### 6.2 动能/功率交叉核对

```text
E_wheel_leg = 0.5*m_0*x_dot^2
              + 0.5*m_p*((x_dot+b*theta_dot)^2 + (a*theta_dot)^2)
              + 0.5*I_p*theta_dot^2
```
```text
E_body = 0.5*M*((x_dot+z*theta_dot-l*cos(phi)*phi_dot)^2
               + (-h*theta_dot-l*sin(phi)*phi_dot)^2)
         + 0.5*I_M*phi_dot^2

E_kinetic = E_wheel_leg + E_body
```
```text
V = m_p*g*b + M*g*(z + l*cos(phi))
Power = T*(x_dot/R - theta_dot) + T_p*(theta_dot + phi_dot)
```

对动能关于速度作 Hessian 即为 H；由功率读取广义输入即为 Du。这也解释了两处 +Tₚ 以及轮电机对腿的 −T 反力矩。

## 7. 平衡点

所有速度、加速度为零时，三条独立方程是

```text
T_e = 0
T_p_e = -M*g*l*sin(phi_e)
```
```text
(m_p*L + M*L_t)*sin(theta_e) + m_p*y*cos(theta_e) = M*l*sin(phi_e)
```

设 c=m_pL+MLₜ、d=m_py，则近直立支为

```text
theta_e = asin(M*l*sin(phi_e) / sqrt(c^2+d^2)) - atan2(d,c)
```

需满足反正弦自变量绝对值不大于 1；另一数学支通常对应倒置构型，不作为本次直立控制目标。位置 xₑ 可任选，因系统对水平平移不变。

当 φₑ=0，得到第 1 节无输入平衡点。若强制 θₑ=0，则必须满足 sinφₑ=m_py/(Ml)，并施加相应 Tₚ 偏置。因此不能独立任意指定 θₑ、φₑ 后仍要求静止。

若在 θ=φ=0、u=0 附近展开，正确形式为仿射系统 `xi_dot = f(0,0) + A_0*xi + B_0*u`，其中加速度常项为 `inverse(H(0))*[m_p*g*y, 0, 0]^T`。由于该点不平衡，A₀ 还包含 H 对角度的导数项，不能直接套下节的平衡点公式。

## 8. 连续状态空间矩阵 A、B

状态记为 ξ，避免和水平位置 x 重名：

```text
xi = [theta, theta_dot, x, x_dot, phi, phi_dot]^T

delta_xi = xi - xi_e
delta_u  = u - u_e
```
```text
delta_xi_dot = A*delta_xi + B*delta_u
```

令 Hₑ=H(θₑ,φₑ)，bₑ=L cosθₑ−y sinθₑ，并定义

```text
k_theta = g*(m_p*b_e + M*L_t*cos(theta_e))
k_phi   = M*g*l*cos(phi_e)
F = inverse(H_e)*diag(k_theta, 0, k_phi)
G = inverse(H_e)*D
```

这里对 u 作独立变量求偏导，**不对平衡输入 uₑ(φₑ) 随状态求导**。平衡点 rhs=0，所以对 H⁻¹ 求导的项乘零消失；所有速度平方项的一阶导数也为零。

```text
A = [  0   1  0  0   0   0
      F11  0  0  0  F13  0
       0   0  0  1   0   0
      F21  0  0  0  F23  0
       0   0  0  0   0   1
      F31  0  0  0  F33  0 ]

B = [  0    0
      G11  G12
       0    0
      G21  G22
       0    0
      G31  G32 ]
```

与参考图片 A₁～A₆、B₁～B₆ 对应的显式标量系数如下，C 和 Δ 均在平衡点求值：

| 系数 | 结果 | 系数 | 结果 |
|---|---|---|---|
| A₁ | C₁₁kθ/Δ | A₂ | C₁₃kφ/Δ |
| A₃ | C₁₂kθ/Δ | A₄ | C₂₃kφ/Δ |
| A₅ | C₁₃kθ/Δ | A₆ | C₃₃kφ/Δ |
| B₁ | (−C₁₁+C₁₂/R)/Δ | B₂ | (C₁₁+C₁₃)/Δ |
| B₃ | (−C₁₂+C₂₂/R)/Δ | B₄ | (C₁₂+C₂₃)/Δ |
| B₅ | (−C₁₃+C₂₃/R)/Δ | B₆ | (C₁₃+C₃₃)/Δ |

这就是所需方程组线性化后的全部系数。偏心导致 H 和平衡点变化，但在固定构型静止平衡点，矩阵的零元素布局仍与参考图片一致。

## 9. 本轮采用的符号表达式

本轮先停在符号 A/B，不生成代入参数后的数值矩阵。令平衡点满足第 7 节条件，并按第 8 节计算 H_e、F、G，则完整线性模型为：

```text
xi_e = [theta_e, 0, x_e, 0, phi_e, 0]^T
u_e  = [0, -M*g*l*sin(phi_e)]^T

delta_xi_dot = A_e*delta_xi + B_e*delta_u
```

```text
A_e = [  0   1  0  0   0   0
        F11  0  0  0  F13  0
         0   0  0  1   0   0
        F21  0  0  0  F23  0
         0   0  0  0   0   1
        F31  0  0  0  F33  0 ]

B_e = [  0    0
        G11  G12
         0    0
        G21  G22
         0    0
        G31  G32 ]
```

其中 H_e = H(theta_e,phi_e)，F = inverse(H_e)*diag(k_theta,0,k_phi)，G = inverse(H_e)*D；A₁～A₆、B₁～B₆ 的通式见第 8 节。到这一步仍未代入任何物理参数值。

## 10. 状态转移、离散化和 LQR

严格说，A 是连续系统矩阵；零输入状态转移矩阵是

```text
Phi(t) = expm(A*t)

delta_xi(t) = expm(A*t)*delta_xi(0)
              + integral(tau=0..t,
                  expm(A*(t-tau))*B*delta_u(tau) d_tau)
```

零阶保持、周期 Tₛ 下：

```text
A_d = expm(A*T_s)
B_d = integral(tau=0..T_s, expm(A*tau)*B d_tau)

delta_xi[k+1] = A_d*delta_xi[k] + B_d*delta_u[k]
```

通过分块指数精确计算：

```text
J = [ A(6x6)    B(6x2)
      0(2x6)    0(2x2) ]

expm(J*T_s) = [ A_d(6x6)  B_d(6x2)
               0(2x6)    I(2x2)   ]
```

A 含位置积分状态，通常不可逆，故不要用 A⁻¹(A_d−I)B。I+ATₛ、BTₛ 仅为一阶近似。

已新增 `Matlab/serial_leg_state_space.m`，可直接生成连续及离散矩阵，不依赖符号工具箱：

```matlab
% p 中仅填写符号参数对应的值；本轮先不填写或代入数值。
% 字段：R,Lt,L,y,l,mw,mp,M,Iw,Ip,IM,g
% 例如在参数确定后，才调用：
[A,B,xe,ue,Ad,Bd] = serial_leg_state_space(p,0,0.001);

% Q、Ru 由实机允许误差/力矩选定，不能直接抄并联腿增益。
% 连续设计：K = lqr(A,B,Q,Ru);
% 离散设计：Kd = dlqr(Ad,Bd,Qd,Rd);
% 控制：u = ue - K*(state-xe)，或离散 Kd。
```

这里未把具体参数代入、未选择 Q/R，也未生成数值 K。先检查符号模型和配平关系；确定何时进入数值计算后，再用确认的参数调用函数。离散 Qd/Rd 的选取和连续 Q/R 的等效转换是另一项设计步骤，不能宣称任意同名权重完全等价。

1. **沿用已确认的等效传动。** 按用户说明保留 fivebar_fk 及相应雅可比，不因结构名称改用普通二连杆公式。后续若修改传动比或编码器坐标，再相应变换雅可比；动力学质量属性使用去杆后的实际单腿数据。

3. **角度和位移单位。** INS.Pitch 已转为 rad。腿长从 mm 转为 m；轮位移与轮速需换算到世界前向。两侧编码器和电机镜像符号分别确认。
4. **力矩单位和符号。** 模型 Tₚ 单位为 N·m，当前 VMC 的 `T_p_Nmm` 为 N·mm，`T_p_Nmm=1000*Tₚ`。按当前机体系 x 前/y 下且 φ 同本文，`leg_axis_angle_rad=θ+φ+π/2`，模型髋功率为 Tₚ·`leg_axis_angle_rad` 的角速度，可与 VMC 正切向定义对应；实物驱动器正方向仍须单独核对。
5. **轮输出尚缺标定。** `WheelTorque_Send` 的形参虽叫 T，实际上直接变成协议整数，必须按电机、减速比、力矩常数和驱动协议建立转换，再承接模型 T；同时替换任务中的固定 1000 指令。
6. **平衡点和前馈。** 控制偏差使用 θ−θₑ、φ−φₑ 等，输出加 uₑ。腿长支撑 F₀ 仍由独立高度环处理，它不在本次固定长度的两个输入内。
7. **变腿长。** 每个构型重新更新 L、y、Iₚ、平衡点及 A/B，再算 K。快速伸缩时还会出现 L̇、ẏ、İₚ 等项，单纯按 Lₜ 插值 K 仅是冻结参数近似。
